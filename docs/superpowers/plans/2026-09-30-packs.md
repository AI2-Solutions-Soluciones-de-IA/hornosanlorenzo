# Packs San Lorenzo — plan de implementación

> **Para quien lo ejecute:** SUB-SKILL OBLIGATORIA: usa `superpowers:subagent-driven-development`
> (recomendada) o `superpowers:executing-plans` para implementarlo tarea a tarea. Los pasos van
> con casilla (`- [ ]`) para poder marcarlos.

**Objetivo:** que los siete packs de `Packs_San_Lorenzo_FINALES (2) (3).pptx` se puedan ver y
pedir en la web: precio cerrado, ahorro frente a comprarlo suelto, sabores a elegir y, en el Pack
Cumpleaños, la foto del cliente subida con el pedido.

**Arquitectura:** cada pack es **un producto más** en `productos` (categoría y sección `packs`):
precio, nombre, foto, activo y agotado se editan en el panel como cualquier ficha y el pack entra
en carrito, pedido y Excel por el camino de siempre. **Lo que lleva cada pack vive en código**
(`src/data/packs.ts`): piezas fijas y huecos «a elegir», apuntando a productos de la carta por su
slug. El precio suelto y el ahorro se calculan con los precios de la carta en cada lectura. La
línea del carrito lleva las elecciones; el servidor las valida y el pedido guarda el desglose
(`lineas_pedido.detalle`, jsonb) y la foto (`lineas_pedido.foto_url`). La foto sube **del
navegador directo a Vercel Blob** con un token de un solo uso que da nuestro servidor.

**Stack:** Astro 5 · `@astrojs/vercel` 9 · `pg` 8 · `@vercel/blob` 2.8 (`/client` para la subida
directa) · Zod 3 · React (islas) · Vitest · Tailwind 4 · pnpm.

**Fuente:** `Packs_San_Lorenzo_FINALES (2) (3).pptx` en la raíz del repo (léelo con
`markitdown`). Decisiones de Oscar del 30-9-2026: la foto se sube en la web; las reglas generales
de la diapositiva 10 (reparto 9:00–14:30, antes de las 10:30 solo zona norte, mínimo en fin de
semana) van **aparte, no en este plan**; los nombres son **«Pack Brunch en casa»** y **«Pack Gran
Celebración»**.

  `src/lib/db/productos.test.ts`.
- **Commit solo con todo en verde, encadenado con `&&`**:
  `pnpm test && pnpm check && pnpm build && git commit …`. Nunca `;`.
- **Marca** (`~/.claude/…/memory/brand-guidelines-avellana.md`): sin esquinas redondeadas, sin
  sombras, sin degradados; filete de 1 px avellana; CTA en caramelo (`.btn-primario`); un solo

  más sin preguntar.
- **La franja «antes de las 10:30»** del Pack Reunión y el resto de la diapositiva 10 **no** entran

## Foco de revisión

Lo que ninguna tarea prueba por defecto y más probablemente muerde a quien compra. Cada línea
tiene su prueba en la tarea indicada.

1. **Dos Packs Cumpleaños con sabores distintos en el carrito** son dos líneas, no una con qty 2;
   y cambiar la cantidad de una no toca la otra (Tarea 6).
2. **Un sabor elegido que se agota o se desactiva** entre añadir al carrito y pagar: el checkout
   lo rechaza nombrando el sabor, no con un error genérico (Tarea 3).
3. **Elecciones manipuladas en el navegador** (un producto de otra sección como «empanada», un
   hueco sin elegir, un hueco inventado, una empanada sin la variante pedida): rechazo, nunca
   precio (Tarea 3).
4. **`fotoUrl` que no es nuestra** (otro dominio, otra carpeta del almacén, una URL que no
   existe) o que falta en el Pack Cumpleaños: rechazo (Tareas 3 y 7).
5. **Una pieza que sube de precio en el panel** hasta que el pack deja de ahorrar: la ficha no
   enseña un «−0 %» ni un ahorro negativo; simplemente no enseña ahorro (Tarea 1).

```ts
export type ProductoPieza = {
  slug: string;
  name: string;
  seccion: string | null;
  priceCents: number | null;
  consultar: boolean;
  activo: boolean;
  agotado: boolean;
  variantes: { variantId: string; label: string; priceCents: number }[];
};

export type PiezaFija = {
  tipo: "fija";
  slug: string;
  variantId?: string;
  /** Lo que se lee en la ficha: «24 bollos preñaos asturianos». */
  titulo: string;
  /** Segunda línea de la ficha, en pequeño. */
  descripcion: string;
  /** Solo la foto comestible del Pack Cumpleaños. */
  requiereFoto?: true;
  /**
   * Nombre con el que la pieza llega al pedido y a la hoja de producción, en
   * lugar de «<producto> · <variante>». Solo para la foto: `tarta-retrato` es
   * el suplemento de foto de las tartas y su variante de 15 € se llama
   * «Pequeña», que en un pack con plancha XL confundiría al obrador.
   */
  rotulo?: string;
};

export type HuecoEleccion = {
  tipo: "eleccion";
  /** Clave en `opciones` del carrito y del pedido. Estable: no se renombra. */
  id: string;
  titulo: string;
  descripcion: string;
  /** Etiqueta del desplegable: «Sabor de la empanada». */
  etiqueta: string;
  variantId?: string;
} & ({ seccion: string } | { slugs: readonly string[] });

export type Pieza = PiezaFija | HuecoEleccion;

export type DefinicionPack = {
  slug: string;
  /** Antetítulo de la ficha: «Cumpleaños en casa». */
  ocasion: string;
  personas: { min: number; max: number; texto: string };
  paraQuien: readonly string[];
  /** Consejo del obrador (conservación, horno). Opcional. */
  consejo?: string;
  piezas: readonly Pieza[];
};

export const packs: readonly DefinicionPack[];
export const packPorSlug: (slug: string) => DefinicionPack | undefined;
/** Todos los slugs que una definición puede necesitar leer de la carta, salvo los de sección. */
export function slugsFijos(def: DefinicionPack): string[];
export function seccionesDeHuecos(def: DefinicionPack): string[];

export type Opcion = { slug: string; name: string; priceCents: number };
/** Productos elegibles para un hueco: activos, no agotados, con precio y con la variante pedida. */
export function opcionesDeHueco(h: HuecoEleccion, productos: readonly ProductoPieza[]): Opcion[];

export type PiezaResuelta = {
  slug: string;
  nombre: string;
  varianteLabel: string | null;
  /** Unidades de esa pieza por cada pack. Hoy siempre 1. */
  qty: number;
};

export class PackError extends Error {}
/**
 * Comprueba las elecciones contra la definición y devuelve el desglose.
 * Lanza PackError con mensaje presentable si falta un hueco, sobra uno, la
 * elección no es válida o una pieza fija no se puede vender hoy.
 */
export function resolverPack(
  def: DefinicionPack,
  productos: ReadonlyMap<string, ProductoPieza>,
  opciones: Readonly<Record<string, string>>,
): PiezaResuelta[];

/** Suma de las piezas al precio de carta; en un hueco, la opción más barata. null si falta alguna. */
export function precioSueltoCents(def: DefinicionPack, productos: readonly ProductoPieza[]): number | null;
/** % entero de ahorro, o null si no ahorra (≤ 0) o no se puede calcular. */
export function ahorroPct(precioPackCents: number, sueltoCents: number | null): number | null;
/** Precio por persona redondeado a 10 céntimos, en céntimos. */
export function precioPorPersonaCents(precioPackCents: number, def: DefinicionPack): number;
/** Etiqueta legible de una pieza resuelta: «Empanada de carne · Entera 16–20 rac.» */
export function etiquetaPieza(p: PiezaResuelta): string;
```

/** Precio y etiqueta de un producto en la variante pedida; null si no la tiene. */
function enVariante(x: ProductoPieza, variantId?: string) {
  if (!variantId) {
    // Un producto con tamaños pedido sin tamaño es ambiguo: no vale.
    if (x.variantes.length > 0) return null;
    return { priceCents: x.priceCents!, label: null as string | null };
  }
  const v = x.variantes.find((v) => v.variantId === variantId);
  return v ? { priceCents: v.priceCents, label: v.label } : null;
}

function admitido(h: HuecoEleccion, x: ProductoPieza): boolean {
  return "slugs" in h ? h.slugs.includes(x.slug) : x.seccion === h.seccion;
}

export function opcionesDeHueco(h: HuecoEleccion, productos: readonly ProductoPieza[]): Opcion[] {
  const res: Opcion[] = [];
  for (const x of productos) {
    if (!admitido(h, x) || !vendible(x)) continue;
    const v = enVariante(x, h.variantId);
    if (v) res.push({ slug: x.slug, name: x.name, priceCents: v.priceCents });
  }
  return res;
}

import { handleUpload, type HandleUploadBody } from "@vercel/blob/client";
import { head } from "@vercel/blob";

export const CARPETA_FOTOS = "pedidos-fotos/";
export const TIPOS_FOTO = ["image/jpeg", "image/png", "image/webp"];
export const MAX_BYTES_FOTO = 20 * 1024 * 1024;

const NOMBRE = /^pedidos-fotos\/[a-z0-9-]{1,60}\.(jpe?g|png|webp)$/;

export async function atenderSubida(request: Request, body: unknown) {
  return handleUpload({
    request,
    body: body as HandleUploadBody,
    onBeforeGenerateToken: async (pathname) => {
      // La ruta la propone el navegador: se acepta solo dentro de la carpeta
      // de fotos y con un nombre sin sorpresas.
      if (!NOMBRE.test(pathname)) throw new Error("ruta no válida");
      return {
        allowedContentTypes: TIPOS_FOTO,
        maximumSizeInBytes: MAX_BYTES_FOTO,
        addRandomSuffix: true,
        allowOverwrite: false,
        validUntil: Date.now() + 10 * 60 * 1000,
      };
    },
    // Sin aviso de subida completada: comprobamos la foto al pagar
    // (`esFotoDePedido`), que es cuando importa.
    onUploadCompleted: async () => {},
  });
}

export async function esFotoDePedido(url: string): Promise<boolean> {
  let u: URL;
  try {
    u = new URL(url);
  } catch {
    return false;
  }
  if (u.protocol !== "https:") return false;
  if (!u.hostname.endsWith(".public.blob.vercel-storage.com")) return false;
  if (!u.pathname.startsWith("/" + CARPETA_FOTOS)) return false;
  try {
    // `head` con NUESTRO token: una URL de otro almacén de Blob no la encuentra.
    await head(url);
    return true;
  } catch {
    return false;
  }
}
